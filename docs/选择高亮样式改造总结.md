# 选择高亮样式改造总结：不变色 + 虚线 + 顶点标记

- 日期：2026-08-19
- 涉及包：`three-renderer`、`cad-simple-viewer`
- 目标：选中/悬停实体不再染青绿色；线条改为屏幕固定像素虚线；同时显示实体顶点（grip 点）方块标记

## 1. 需求与交互约定

- 选中（框选/点选）与悬停样式一致：不改变原色、线条变虚线、显示顶点标记
- 宽线（`showLineWeight` 开启，`LineMaterial`/`LineSegments2` 渲染）同样支持虚线
- 网格填充（HATCH 等 Mesh 批次）、点实体、未批处理实体（文字字形树）：不做虚线，仅显示顶点标记（无 `subGetGripPoints` 的实体类型则无额外反馈）
- 写模式下 HTML 夹点（`AcEdGripManager`）显示时，顶点标记自动让位，避免双重方块

## 2. 实现

### 2.1 细线批次补 `lineDistance` 属性（three-renderer）

虚线需要在片元里按"沿线距离"丢弃间隙。此前只有 pattern 线型（`AcTrLinePatternShaders`）的几何带 `lineDistance`，普通细线（`LineBasicMaterial`）与宽线都没有：

- `util/AcTrBufferGeometryUtil.ts`：新增 `computeSegmentLineDistances`，逐实体从 0 累计顶点距离（保证每实体虚线相位独立）。索引路径对每个顶点**首次写入优先**——批次源几何的 index 缓冲带退化填充对（如 2 顶点线配 4 槽 index `[0,1,0,0]`），后续退化对不得覆盖真实段的距离值
- `batch/AcTrBatchedLine.ts`：`addGeometry`/`setGeometryAt` 无条件补算 `lineDistance`，批次初始化（`AcTrBatchedMixin.initializeGeometry`）按参考几何自动分配该属性；`AcTrBatchedGroup` 中两处旧的按需 recompute 移除
- 代价：每线顶点 +4B（约 39 万实体图纸 +3MB GPU 内存），可忽略

### 2.2 高亮 shader 补丁改为"虚线 + 原色"（three-renderer）

`batch/highlight/AcTrBatchHighlightShaders.ts` 重写：

- uniform 袋：删除 `u_highlightSelectColor/u_highlightHoverColor`，新增 `u_highlightDashSize`（8px）、`u_highlightDashGap`（5px）、`u_highlightZoom`（**共享引用** `AcTrMaterialManager.CameraZoomUniform`，与 pattern 线型的屏幕恒定虚线同一约定）
- 顶点注入按材质分流：
  - 细线（`LineBasicMaterial`/pattern `ShaderMaterial`）：注入 `lineDistance` → `vBatchLineDistance`
  - 宽线（`LineMaterial`）：注入 `instanceDistanceStart/End`，沿用 three 自身 `USE_DASH` 的 `position.y < 0.5` 约定取段首/段尾距离
- 片元 `applyBatchHighlight`：命中 select/hover mask 时 `mod(vBatchLineDistance * u_highlightZoom, dash+gap) > dashSize` 则 `discard`，否则**原样返回输入色**（不再染色）
- `resolveDashMode` 按材质类型分流；Mesh/Point 材质直接跳过补丁（不重编译）
- **关键坑（E2E 实测捕获）**：高亮 uniform 不能命名 `u_cameraZoom`——pattern 线型 ShaderMaterial 源码已声明同名 uniform，会 GLSL `redefinition` 编译失败导致整批（整层）消失。故改名 `u_highlightZoom`，值仍引用共享 zoom 对象

### 2.3 宽线批次支持 per-slot 虚线（three-renderer）

`batch/AcTrBatchedLine2.ts`：

- `slotId` 改为 `InstancedBufferAttribute`（原为普通 attribute 挂在 `InstancedBufferGeometry` 上，按基础四边形顶点索引读取，per-slot 高亮实际错位，一并修复）
- 新增每段累计距离 `instanceDistanceStart/End`：`addGeometry` 入口计算（逐实体归零）、`setGeometryAt` 拷贝、`optimize` 搬移、`setGeometrySize` 扩容保留、`_copyStaticAttributes` 排除

### 2.4 顶点标记 overlay（three-renderer + cad-simple-viewer）

- 新增 `object/AcTrVertexMarkerOverlay.ts`：单个 `THREE.Points` + 动态 BufferGeometry；`PointsMaterial({ size: 7, sizeAttenuation: false, color: 0x0080ff, depthTest: false, depthWrite: false })`，`renderOrder = 100000`（高于所有实体批次），屏幕固定大小方块
- `AcTrScene`：构造时挂到 scene 根（随视图变换，无需手动重定位）；`setSelectionVertexMarkers/clearSelectionVertexMarkers`；`clear()` 时随其他管理器一并重建

### 2.5 未批处理实体不再换材质染色（three-renderer）

删除 `AcTrBatchedGroup` 的 unbatched 换材质机制（`_unbatchedSelectedIds/_unbatchedHoveredIds`、`refreshUnbatchedHighlight`、`applyUnbatchedHighlightMaterial`、`getSharedHighlightMaterial` 及共享克隆缓存）。文字等未批处理实体的选中反馈由顶点标记承担。

### 2.6 顶点标记驱动器（cad-simple-viewer）

- 新增 `editor/marker/AcEdSelectionVertexMarkers.ts`：订阅 `selectionSet` 增删与 `view.events.hover/unhover`；从 `blockTable.getEntityById(id).subGetGripPoints()` 收集 WCS 点，逐实体缓存并按当前 id 集合修剪；`acedShouldShowGrips` 为真（HTML 夹点正在显示）时让位清空
- `AcTrView2d`：构造、getter、实体重转换后刷新（与既有 `_gripManager.refresh()` 并排）

## 4. E2E 期间发现并修复的问题

`u_cameraZoom` 与 pattern 线型 ShaderMaterial 同名 uniform 冲突（GLSL redefinition）导致 shader 编译失败、整批线消失。此问题仅在新 uniform 注入路径引入、由 E2E 的 Shader Error 捕获，改名 `u_highlightZoom` 后消除。这是高亮补丁路径继上一轮两个 bug（`onBeforeRender` 裸调用、字面量赋值缺函数定义）后的又一例"补丁与宿主 shader 声明冲突"类问题，防御原则不变：补丁失败时不半补丁、不重编译。

## 5. 遗留

- Mesh/Point/未批处理实体无虚线（仅顶点标记），如需对 HATCH 图案做选中反馈需另议
- 虚线 dash/gap 长度（8px/5px）与顶点方块尺寸（7px）为默认值，未接系统变量（未来可对应 `GRIPSIZE` 等）
- `HIGHLIGHT_SELECT_COLOR/HOVER_COLOR` 常量保留导出（公共 API 兼容），但选中/悬停链路已不再使用
